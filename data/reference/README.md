# 真实参考数据版本

真实码头和锚地数据统一保存在 `实际数据/`，并按交付版本区分：

- `实际数据/码头.csv`、`实际数据/锚地.csv`：2025-05 原始交付，仅作历史追溯。
- `实际数据/实际数据中国版/码头.csv`、`实际数据/实际数据中国版/锚地.csv`：2025-07 中国范围版本；当前看板与码头评估优先使用此版本。
- `实际数据/processed/中国锚地_去重.csv`：由 2025-07 锚地版本去除近乎完全覆盖的重复面后生成；第 09 轮及后续锚地评估与看板使用它。第 01–08 轮保留原始版本，以保持其历史对照口径。
- `实际数据/processed/中国锚地_去重记录.csv`：上述处理的审计记录。

新增交付请新建带日期或来源说明的目录，保留原文件，并同步更新本说明与 `data/README.md`。
