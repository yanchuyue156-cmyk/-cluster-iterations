## 当前规则

- `src.common.main` 不指定 `--output-dir` 时，会自动写入下一个编号目录。
- `src.iterations.run` 仅在迭代成功后写入 `results/iterations/<迭代名>/`；同名结果存在时会拒绝覆盖。
- 地图看板导出工具默认读取编号最大的结果目录；查看迭代结果时，用 `--result-dir` 明确指定目录。
- `cache/` 是停泊段缓存，不是结果版本，不参与编号。
