# 预测码头与真实码头对比：iteration_15_terminal_non_overlapping_rectangles

## 匹配方法

1. 预测码头使用 `china_terminals.csv` 的 AIS 活动中心（`lat`、`lon`）与预测范围面。
2. 真实码头使用参考数据的 `point` 作为中心、`geom` 作为范围面。
3. 真实码头中心可位于近岸水域，因此评估范围为中国与台湾陆地及其 50 km 近岸海域；落在范围外的参考记录不删除，只是不参与本次中国范围评估。
4. 只保留两中心距离不超过 2,000 m 的候选对，并采用最小总中心距离的一对一匹配。每个预测码头和每个真实码头最多匹配一次；不能在半径内匹配的对象视为未匹配。
5. 所有面积与叠加指标均在 EPSG:3857 米制坐标中计算。

## 形状重叠

- IoU = `预测面与真实面交集 / 两者并集`，越接近 1 表示形状与位置越一致。
- 预测面积精度 = `交集 / 预测面积`，用于判断预测范围有多少落在真实范围内。
- 真实面积召回 = `交集 / 真实面积`，用于判断真实范围被预测覆盖了多少。

| 指标 | 中位数 | P90 |

| IoU | 0.273 | 0.485 |
| 预测面积精度 | 0.397 | 0.855 |

## 放宽的一对多/多对多范围覆盖

这一层不使用中心距离，也不限制一对一关系：只要预测面与真实面有交集，就共同参与覆盖面积计算。它回答的是“所有紫色预测面合起来，覆盖了多少绿色真实面”，适合预测码头与参考码头的拆分粒度不同的情形。

| 指标 | 数值 |
| --- | ---: |
| 与至少一个真实面相交的预测码头 | 563 / 738 |
| 被至少一个预测面相交的真实码头 | 649 / 922 |
| 预测面覆盖精度（全局并集） | 0.422 |

逐对严格匹配见 `terminal_comparison_pairs.csv`；多对多覆盖明细见 `terminal_overlay_by_prediction.csv` 和 `terminal_overlay_by_reference.csv`。该报告评价的是参考数据中记录的码头范围与 AIS 推断活动范围的一致性，不应被解释为法定或运营边界的真值判定。

## 用户定义的“预测合格率”

本指标不要求预测面与真实面形状、面积或拆分粒度相同，也不要求一对一匹配。只要一张预测面与任意一张真实面拥有大于 1 ㎡ 的共同面积，就计为合格；只有边界相碰、没有共同面积的情况不计入。

| 指标 | 计算方式 | 结果 |
| --- | --- | ---: |
| 预测合格率 | 至少与一个真实面有效相交的预测码头 / 全部预测码头 | 563 / 738 (76.3%) |
| 真实码头发现率 | 至少与一个预测面有效相交的真实码头 / 全部真实码头 | 649 / 922 (70.4%) |
| 合格空间关系对 | 所有有效相交的预测/真实面组合 | 842 |

| 合格关系 | 组合数 |
| --- | ---: |
| 预测包含真实 | 155 |
| 真实包含预测 | 32 |
| 部分重叠 | 655 |
| 范围相同 | 0 |

详细的每一组空间关系见 `terminal_qualifying_spatial_relations.csv`。
