# 预测锚地与处理后真实锚地对比：iteration_12_anchorage_seaward_envelope_6km

## 评估口径

- 真实锚地使用 `data/reference/实际数据/processed/中国锚地_去重.csv`：已删除近乎完全覆盖的重复面，并裁掉与更大面重叠的部分。
- 中心一对一匹配半径为 10 km；中心指标用于辅助定位，不作为唯一正确性判断。
- 面积指标与“预测合格率”均在 EPSG:3857 米制坐标计算。面之间有大于 1 ㎡ 的交集即为有效相交。

## 中心一对一匹配

| 指标 | 数值 |
| --- | ---: |
| 预测锚地 | 104 |
| 真实锚地 | 136 |
| 一对一匹配对 | 43 |
| 中心距离中位数 | 4217 m |
| 中心距离 P90 | 9421 m |
| IoU 中位数 | 0.339 |

| 单对真实面积召回中位数 | 0.933 |

## 多对多范围准确性

| 指标 | 结果 |
| --- | ---: |
| 预测面积精度（全局并集） | 0.437 |
| 真实面积召回（全局并集） | 0.276 |
| 面范围 IoU（全局并集） | 0.203 |
| 预测合格率 | 65 / 104 (62.5%) |
| 真实锚地发现率 | 81 / 136 (59.6%) |
| 合格率 F1 | 0.610 |

“预测合格率”衡量预测面是否落入任一真实锚地，“真实锚地发现率”衡量真实面是否被任一预测面触及；全局面积精度、召回和 IoU 则评价范围大小与位置。逐对中心匹配见 `anchorage_comparison_pairs.csv`，多对多覆盖明细见 `anchorage_overlay_by_prediction.csv`、`anchorage_overlay_by_reference.csv` 和 `anchorage_qualifying_spatial_relations.csv`。
